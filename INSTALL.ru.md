Установка Maccy — форк с улучшенной историей изображений

Требования: macOS 14 Sonoma или новее, Apple Silicon или Intel.

1. Закройте уже запущенный Maccy через его меню → Quit / Выход.
2. Откройте Maccy.dmg и перетащите Maccy.app в Applications / Программы.
3. Запустите Maccy из Программ. Если macOS блокирует запуск, откройте
   Системные настройки → Конфиденциальность и безопасность → Всё равно открыть.
   Эта сборка не заверена Apple Developer ID и не нотарифицирована.
4. Для автоматической вставки разрешите Maccy в Системных настройках →
   Конфиденциальность и безопасность → Универсальный доступ.
   Копирование из истории и обычное ⌘V работают без этого разрешения.
5. Откройте историю через ⇧⌘C или значок в строке меню.
   Правой кнопкой по картинке → «Копировать изображение» / «Вставить изображение».
   Перед вставкой активным должно быть нужное окно и поле ввода.

Обновления: настройки Maccy → Основные → Проверить сейчас.
Обновления берутся только из nekell3r/Maccy и проверяются подписью Sparkle.
После замены сборки macOS может попросить заново разрешить Универсальный доступ.

и настройки. Одновременно запускать оригинал и форк не следует.
