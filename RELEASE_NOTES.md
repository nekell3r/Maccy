Готовая Release-сборка Maccy с улучшенной историей изображений.

- Превью изображений и скриншотов в истории, поиск по распознанному тексту.
- «Копировать изображение» и «Вставить изображение» в меню конкретной картинки.
- Сохранение PNG/TIFF/JPEG/HEIC и восстановление исходных данных из истории.
- OCR обрабатывает изображения в отдельной очереди и не блокирует общий пул Swift.
- Обновления только из этого форка, с проверкой подписи Sparkle.

**Установка:** скачайте `Maccy.dmg`, откройте и перетащите Maccy в Applications.
macOS 14+, Apple Silicon и Intel в одном приложении. Закройте старый Maccy перед заменой.

Сборка не нотарифицирована Apple. Если macOS блокирует запуск, разрешите его через
«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
Для автоматической вставки включите Maccy в разделе «Универсальный доступ».
Вставка идёт в активное окно: сначала выберите нужное поле ввода, затем откройте историю.

Выпуск публикуется автоматически после unit-тестов, UI-тестов, проверки DMG,
универсального бинарника и запуска Release-приложения на отдельном macOS-раннере.
`SHA256SUMS` содержит контрольные суммы DMG и ZIP. ZIP также используется для обновлений.
